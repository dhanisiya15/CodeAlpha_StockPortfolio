# CodeAlpha Stock Portfolio Tracker

## Description
A simple Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship.

## Features
- Displays available stocks and prices
- Accepts stock name from the user
- Accepts quantity of stocks
- Calculates investment value
- Calculates total portfolio investment
- Uses hardcoded stock prices
- Simple command-line interface

## Technologies Used
- Python
- Dictionary
- Loops
- Conditional Statements
- User Input

## Available Stocks
- AAPL
- TSLA
- GOOGL
- MSFT
- AMZN

## How to Run

```bash
python stock_portfolio.py
